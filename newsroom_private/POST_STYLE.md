## Типографика

- Короткий цепляющий жирный лид/заголовок. КАПС — выборочно под сильный повод; правило КАПС+эмодзи обязательно для подписей ВИДЕО, не автоматически для всех новостей.
- В основном тексте максимум одно дополнительное выделение: важная цифра, действие или необычная деталь. Не весь абзац.
- Короткие абзацы, нормальная пунктуация. Запрет точек/запятых касается видеосубтитров, НЕ новостных постов.
- Финальная короткая реплика может дать сухой панч. Не заканчивать каждый пост одинаковым вопросом. Курсив — необязателен, по текущей выборке не универсальное правило. Не копировать дословные шутки/концовки РиП.
