# Облако и расходы

Проверено 5 ноября 2026, HTTP-доступ к официальным тарифам успешен. Цены в USD, без банковской конвертации и налогов. Новых расходов, покупки услуг и платных API-вызовов в этой задаче не было.

## Рекомендация

**GitHub Actions, стандартный Linux runner, существующий публичный репозиторий.** Проверки 09/12/15/18/21 по Москве = `0 6,9,12,15,18 * * *` UTC, 150 запусков за 30 дней. Постоянно включённый сервер не нужен. Компьютер пользователя, Beget и среда Codex для исполнения расписания не нужны.

| GitHub Actions, стандартный runner публичного репозитория | $0 за вычисления |
| Telegram Bot API | Без отдельной платы за обычные публикации в этом объёме; платную рассылку не используем |
| Состояние и журнал | Обычные небольшие файлы в отдельной ветке Git, без БД, Git LFS и Actions cache |

**Ориентир: $0 за облако + около $0.8–1.4/месяц за текстовый API при указанных размерах запросов.** Это расчёт, не измеренный расход работающего бота: API-ключа редакции пока нет, модель на этом аккаунте не проверена. Более длинные источники и дополнительные попытки увеличат расход. Предлагаемый начальный программный предел — $2/месяц, только после согласия пользователя. Сейчас `monthly_budget_usd=0` и разрешения на платные запросы нет.

Перед API-запросом редакция сохраняет завышенный резерв на обе стадии, затем учитывает возвращённые API данные usage. При таймауте резерв остаётся; автоматического повтора платного запроса нет. Поэтому предел может остановить работу раньше фактического исчерпания денег. Это ограничитель данного приложения, не общий лимит расходов аккаунта OpenAI. Отдельный API project со своим ключом изолирует учёт; ChatGPT Plus не оплачивает API автоматически.

Артефакты Actions по умолчанию **выключены** (`NEWSROOM_SAVE_ARTIFACTS` не задан). Их хранение тарифицируется отдельно от бесплатных вычислений, поэтому оно не входит в безусловное обещание $0. При необходимости очереди на скачивание можно отдельно разрешить артефакты на 7 дней после проверки общего лимита хранения аккаунта. Постоянные журналы от них не зависят.

## Сравнение

| Вариант | Вывод |
|---|---|
| GitHub Actions, публичный repo | Выбран: бесплатные стандартные вычисления, Python без установки пакетов, существующий аккаунт. Возможны задержки cron. |
| Cloudflare Workers Free | 100 000 запросов/день, 10 мс CPU/вызов по таблице тарифов; потребует переноса редакции в JS и проверки CPU на разборе нескольких страниц. Для текущего Python-проекта не даёт экономии против $0 Actions. |
| Cloudflare Workers Paid | Минимум $5/месяц; для 150 проверок не требуется. |
| GPT-4o mini вместо GPT-4.1 mini | Тариф дешевле: $0.15/$0.60 за млн токенов; тот же пример = $0.3078–0.513/месяц. Русскую редактуру и фактчекинг этим вариантом ещё не проверяли, поэтому не выдаём его за равноценную замену. |

GitHub cron — запуск с возможной задержкой, а не гарантия до минуты. Редакция пропускает публикацию, если запуск вышел за первые 45 минут нужного часа. При отсутствии активности репозитория 60 дней GitHub может отключить расписание; это проверяется в Actions. Не обещаем 2–3 подтверждённые новости, если источники их не дали.

## Официальные источники цен

- https://docs.github.com/en/billing/concepts/product-billing/github-actions — стандартные runners публичных репозиториев бесплатны; хранение отдельно.
- https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule — задержки, default branch и 60 дней.
- https://developers.cloudflare.com/workers/platform/pricing/ — Free и минимум $5 Paid.
- https://developers.openai.com/api/docs/pricing — строки `gpt-4.1-mini` и `gpt-4o-mini`, Standard. В HTML страница содержит таблицы нескольких тарифных режимов: не путать Standard с Batch/Priority.
- https://core.telegram.org/bots/api — обычные методы getMe/getChat/getChatMember/sendMessage/sendPhoto; платный режим рассылки не включён.

Репозиторий `rogovvlad960-oss/gta6` проверен через GitHub API: `private=false`. На удалённой стороне пока нет исходного коммита (`git ls-remote origin HEAD` пуст), поэтому расписание ещё не может работать. В этой задаче код не отправлялся в GitHub и облачный сервис не активировался: сначала предлагаются вариант, стоимость и стиль.
