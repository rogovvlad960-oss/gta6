# GTA emoji pack

Пак пользователя реально получен через getStickerSet: GamingEmoji_by_MoiStikiBot, custom_emoji, 148 элементов. Ключи/секретные URL не сохранены. В каталог добавлены public custom_emoji_id, fallback-символ и локальное превью. Для анимированных элементов это неподвижная thumbnail, а не замена оригинальной анимации.

Подборка: GTA VI logo, lightning, minimap, VI mark. Семантику нельзя определять только по fallback-символу: у многих элементов фактическая картинка не соответствует стандартному emoji (например, контроллер может оказаться портретом персонажа). Подборка просмотрена визуально.

Официальное ограничение проверено 06.11.2026: https://core.telegram.org/bots/api#formatting-options . Custom emoji entities can only be used by bots that purchased additional usernames on Fragment, OR in messages sent directly to PRIVATE, GROUP and SUPERGROUP chats if the bot owner has Premium. Второе условие не включает channel. Наличие права can_post_messages или успешное чтение набора не доказывает право отображать custom emoji в сообщении канала.

Статус текущего бота по Fragment не проверен; HTML tg-emoji НЕ включён. Не покупать имена/подписки без отдельного согласия пользователя, не отправлять пробные сообщения без согласованного теста. Публикаций при изучении пака не было.

Бесплатная альтернатива для автоматизации — использовать PNG-значки как маленькие декоративные элементы карточек (максимум 1–2, без лишних персонажей и водяных знаков). Это графика внутри изображения, не активные анимированные emoji в подписи. Для ручной публикации пользователь с Premium может применять пак своим аккаунтом.
